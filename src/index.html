Deck to Print

Name a commander or paste a deck list, and get every card as a print-ready image, numbered in order, with an order file a helper program can load into the card printer for you. Two decks share one set of cards: one on the fronts, the other on the backs.

1Choose your decks

Type a commander's name to get a ready-made deck, a starter deck built for you, or links to lists other players built. Or paste a list of your own: in Moxfield or Archidekt, open the deck, choose Export, copy the text and paste it. One card per line, like 1 Sol Ring. Only Magic: The Gathering cards for now.

          Ordering through MPC Autofill

            MPC Autofill is a free community project and is separate from this page. Its server only answers its own site, so this page cannot fetch its pictures for you. That is why the list is pasted there. For a single deck you can also give that site your deck link directly.

            Save the file again

            Hands-free: a helper program fills in the order

              The helper is the MPC Autofill desktop tool, a free community program that is separate from this page. It works your browser for you on MakePlayingCards. The cards.xml file in the download tells it exactly which picture goes on which card, front and back, so the pairs cannot slip. The start file is plain text: open it in a text editor to see everything it does.

              Or by hand, on MakePlayingCards

                Both sets of steps are also saved inside the download. The printing site changes its pages from time to time, so button names may differ a little. Any printer that takes one image per card will work: each image is 822 by 1122 pixels with the trim margin they ask for.

                For personal playtest cards only. Do not sell what you print and do not use it in sanctioned events. This tool never prints an official card back.
